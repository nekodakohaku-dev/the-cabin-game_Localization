## 繁體中文

本專案是 **The Cabin Game 的非官方本地化補丁**，目前提供繁體中文、簡體中文及日文版本，翻譯遊戲中的選單、設定、卡牌、事件與手冊等文字。

### 安裝／升級

1. 從本專案的 **Releases** 下載所需語言的 ZIP，完全關閉遊戲並將 ZIP 完整解壓縮。
2. 執行 `Install.cmd`，程式會自動尋找 Steam 的遊戲安裝位置。首次安裝可能需要網路連線。
3. 若無法自動識別，依提示輸入 **`the_cabin_game.exe` 所在資料夾**的路徑。可從 Steam → 遊戲右鍵 → 管理 → 瀏覽本機檔案取得。
4. 顯示安裝完成後，正常從 Steam 啟動遊戲，確認文字顯示正常。

升級或切換語言時，關閉遊戲後執行新套件的 `Install.cmd` 即可。

### 移除補丁

1. 完全關閉遊戲，執行解壓資料夾中的 `Uninstall.cmd`。
2. 程式會自動尋找遊戲位置；若無法識別，依提示輸入與安裝時相同的遊戲資料夾路徑。
3. 顯示已停用補丁後，重新從 Steam 啟動遊戲，即可恢復原版英文。

停用的語言補丁會移至遊戲資料夾中的 `zhTW-backups`，原始遊戲封包與存檔不會修改。遊戲更新後若出現文字或啟動異常，請先移除補丁並等待相容版本。

### 問題回報

若遊玩時發現 Bug、漏譯、語句不通順或排版問題，歡迎到本專案的 **Issues** 頁面回報；也可在 Steam 本補丁討論串回報。

請盡量提供：使用語言、補丁與遊戲版本、發生問題的場景或操作步驟，以及原文或畫面截圖。若是安裝失敗，也請附上安裝視窗的錯誤訊息；公開前請檢查並遮蔽個人路徑等資訊。

### 第三方授權與原始碼

本補丁使用 **repak** 與 **Noto Sans TC／SC／JP** 字型。第三方元件授權請參閱安裝包內的 `licenses`，安裝程式原始碼位於本專案的 `src`，各語言的譯文與發布套件位於 `packages`。重新散布時請保留相關授權聲明。

本補丁為非官方製作，未獲遊戲開發者背書。未附遊戲本體或原始遊戲封包。
