## 日本語

本プロジェクトは **The Cabin Game の非公式ローカライズパッチ**です。繁体字中国語、簡体字中国語、日本語に対応し、メニュー、設定、カード、イベント、マニュアルなどのテキストを翻訳します。

### インストール／更新

1. 本プロジェクトの **Releases** から希望する言語のZIPをダウンロードし、ゲームを完全に終了してZIPをすべて展開します。
2. `Install.cmd` を実行します。Steamのゲームインストール先を自動的に検索します。初回はインターネット接続が必要になる場合があります。
3. 自動検出できない場合は、案内に従って **`the_cabin_game.exe` があるフォルダー**のパスを入力します。Steamでゲームを右クリック → 管理 → ローカルファイルを閲覧すると確認できます。
4. インストール完了の表示後、通常どおりSteamからゲームを起動し、文字が正常に表示されることを確認します。

更新や言語の切り替えは、ゲームを終了してから新しいパッケージの `Install.cmd` を実行してください。

### パッチのアンインストール

1. ゲームを完全に終了し、展開したフォルダー内の `Uninstall.cmd` を実行します。
2. ゲームの場所を自動的に検索します。検出できない場合は、インストール時と同じゲームフォルダーのパスを入力します。
3. パッチを無効にした旨の表示後、Steamからゲームを再起動すると原版の英語に戻ります。

無効にした言語パッチはゲームフォルダーの `zhTW-backups` に移動します。元のゲームパッケージとセーブデータは変更しません。ゲーム更新後に文字表示や起動の問題が発生した場合は、パッチをアンインストールして対応版をお待ちください。

### 不具合の報告

バグ、未翻訳、不自然な表現、レイアウトの問題は、本プロジェクトの **Issues** にご報告ください。Steamの本パッチのスレッドでも報告できます。

使用言語、パッチとゲームのバージョン、問題が発生した場面や操作手順、原文またはスクリーンショットをできるだけ添えてください。インストールに失敗した場合は、インストーラーに表示されたエラーメッセージも添えてください。公開前に個人情報を含むパスなどを確認し、伏せてください。

### 第三者のライセンスとソースコード

本パッチは **repak** と **Noto Sans TC／SC／JP** フォントを使用しています。第三者のライセンスはパッケージ内の `licenses`、インストーラーのソースは本プロジェクトの `src`、各言語の翻訳データと配布用ファイルは `packages` にあります。再配布時はライセンス表記を保持してください。

本パッチは非公式であり、ゲーム開発者による承認・推奨を受けていません。ゲーム本体や原版のゲームパッケージは含みません。
