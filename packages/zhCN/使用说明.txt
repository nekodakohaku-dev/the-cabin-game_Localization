The Cabin Game 非官方简体中文补丁 v0.1.0
发布日期：2026-10-02

【安装】
1. 玩家必须先自行从 Steam 安装 The Cabin Game。
2. 完全关闭游戏，将 ZIP 完整解压缩。不要在 ZIP 内直接运行。
3. 双击「安装简体中文.cmd」。不需要安装 Python、Unreal Engine 或以管理员运行。
4. 如需输入路径：Steam 游戏库 → 右键游戏 → 管理 → 浏览本机文件。
   拷贝该文件夹路径，贴到安装程序后按 Enter。
   正确文件夹中应有 the_cabin_game.exe、Engine 与 the_cabin_game。
   也可将这整个补丁文件夹放在游戏根目录内，程序会自动辨识。
5. 看到「安装完成」后，照常从 Steam 打开游戏。

【首次安装需要网络】
本包未附 Oodle DLL。repak 在解压原版语系时，会依其上游机制下载解压缩
组件并校验 SHA256，保存在本包 tools 目录。请保持网络连接与该目录可写。
若解压失败，安装会停止，原始游戏封包不会被修改。
不需修改系统安全设置。CMD 的 Bypass 仅适用本次 PowerShell 行程。

【卸载】
关闭游戏，双击「卸载.cmd」，指定同一个游戏文件夹。
它只会将本补丁移到游戏根目录下的 zhTW-backups，重新启动后恢复英文。
重新运行安装即可再次使用简中。其他模块与存盘不会被修改。

【版本兼容性】
仅支持 2026-10-02 本次测试的游戏资源版本；以 manifest.json 中原版 PAK
和 UTOC 的 SHA256 识别，日期不是游戏的正式版本号。
游戏更新造成内容不符时，安装会拒绝继续；不要强行跳过检查。
已安装补丁后若游戏更新出现异常，先卸载，等待兼容新版。

【内容与测试范围】
512 种译文、666 个文本识别码，涵盖菜单、设置、角色能力、道具、事件、
线索及手册文本。字体为 Noto Sans SC 的简中子集，覆盖 8 个游戏字体及后备字体。
已实测 Steam 启动、开场警告、主菜单、操作设置、画质设置及车库页。
未逐一实测游戏内事件、角色能力、手册与多人流程。
Input Type、Keyboard、部分平台按键名称及动态下拉列表仍可能显示英文。
图片中的英文、配音与未截取到的文本不在本次补丁范围内。
部分英文按键名称可能被原版固定字段裁切，尚待排版调整。

【分享方式】
分享这份完整 ZIP 即可，不要附带游戏安装目录、原版封包或安装后产生的 PAK。
本分享包只有译文识别码、中文译文、开源工具、中文本型和安装脚本。
安装时会从玩家自己的原版封包读取引擎语系，合并后在本机产生 PAK。
本补丁为非官方制作，并非游戏开发者发布或背书。

Noto Sans SC 已固定为字重 400 并裁切为本补丁使用的字符。
完整授权文档位于 licenses；分享时请一并保留。
语系格式参考：https://github.com/akintos/UnrealLocres

【语言切换与更新】
安装简中 v0.1.0 或日文版时，会先验证新补丁，再备份并停用另一个语言版本。
要切换语言，关闭游戏后运行对应包的 Install.cmd 即可。
本工具只在安装时检查游戏版本，并不会在 Steam 启动时自动检查或停用。
游戏更新后，既有补丁仍可能被加载；如有文本或启动问题，先运行 Uninstall.cmd，等待新版。

三种语言切换请使用繁中 v0.2.3、日文 v0.1.1 或简中 v0.1.0 的安装工具。
