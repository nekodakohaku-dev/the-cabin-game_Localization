## 繁体中文

本项目是 **The Cabin Game 的非官方本地化补丁**，目前提供繁体中文、简体中文及日文版本，翻译游戏中的菜单、设置、卡牌、事件与手册等文本。

### 安装／升级

1. 从本项目的 **Releases** 下载所需语言的 ZIP，完全关闭游戏并将 ZIP 完整解压缩。
2. 运行 `Install.cmd`，指定 **`the_cabin_game.exe` 所在文件夹**。首次安装可能需要网络连接。
3. 正常从 Steam 启动游戏，确认文本显示正常。

升级或切换语言时，关闭游戏后运行新套件的 `Install.cmd` 即可。运行 `Uninstall.cmd` 可恢复原版英文。游戏更新后若出现文本或启动异常，请先卸载并等待兼容版本。

### 问题回报

若游玩时发现 Bug、漏译、语句不通顺或排版问题，欢迎到本项目的 **Issues** 页面回报；若有在 Steam 发布本补丁讨论串，也可在该讨论串回报。

请尽量提供：使用语言、补丁与游戏版本、发生问题的场景或操作步骤，以及原文或画面截屏。若是安装失败，也请附上安装窗口的错误消息；公开前请检查并屏蔽个人路径等信息。
