## 繁体中文

本项目是 **The Cabin Game 的非官方本地化补丁**，目前提供繁体中文、简体中文及日文版本，翻译游戏中的菜单、设置、卡牌、事件与手册等文本。

翻译使用 AI 辅助制作，部分游戏画面仍在持续校对与调整。

### 安装／升级

1. 从本项目的 **Releases** 下载所需语言的 ZIP，完全关闭游戏并将 ZIP 完整解压缩。
2. 运行 `Install.cmd`，程序会自动寻找 Steam 的游戏安装位置。首次安装可能需要网络连接。
3. 若无法自动识别，依提示输入 **`the_cabin_game.exe` 所在文件夹**的路径。可从 Steam → 游戏右键 → 管理 → 浏览本机文件取得。
4. 显示安装完成后，正常从 Steam 启动游戏，确认文本显示正常。

升级或切换语言时，关闭游戏后运行新套件的 `Install.cmd` 即可。

### 移除补丁

1. 完全关闭游戏，运行解压文件夹中的 `Uninstall.cmd`。
2. 程序会自动寻找游戏位置；若无法识别，依提示输入与安装时相同的游戏文件夹路径。
3. 显示已停用补丁后，重新从 Steam 启动游戏，即可恢复原版英文。

停用的语言补丁会移至游戏文件夹中的 `zhTW-backups`，原始游戏封包与存盘不会修改。游戏更新后若出现文本或启动异常，请先移除补丁并等待兼容版本。

### 问题回报

若游玩时发现 Bug、漏译、语句不通顺或排版问题，欢迎到本项目的 **Issues** 页面回报；也可在 Steam 本补丁讨论串回报。

请尽量提供：使用语言、补丁与游戏版本、发生问题的场景或操作步骤，以及原文或画面截屏。若是安装失败，也请附上安装窗口的错误消息；公开前请检查并屏蔽个人路径等信息。
